# X横扫与Y换行速度分开设置

配置文件为 `firmware/Core/Inc/snake_scan_config.h`，单位μm/s：

```c
#define SCAN_SPEED_UM_PER_SEC  10000UL  /* X横扫和单向回程：10 mm/s */
#define Y_SPEED_UM_PER_SEC      1000UL  /* Y换行：1 mm/s */
```

这只是配置示例；仓库默认X、Y均1 mm/s。X的旧宏名保留，Y新增独立字段。修改X不会自动修改Y。参数界面和实验准备界面也分别提供两个输入框，不使用界面时直接改这两行即可。

## 使用步骤

1. 复制完整项目或独立实验工程，核对地址、方向、安全行程与导程/细分。
2. 设置X和Y速度。Y先维持已经确认可稳定运行的低速值；不要仅因提高X速度就同步提高Y。
3. 在Keil中先编译下载通信检查，再用小行程检查方向与运行；最后编译正式04工程。只改头文件而不重新编译下载不会改变电机配置。
4. 单向模式仍为X扫描→X同速回程→Y换行。双向模式为X交替横扫→Y换行。实验三自动梯度模式4/5/6的被测轴速度由梯度表控制，独立Y字段不覆盖该表。
5. 保存实际烧录头文件与运行记录。重构时记录X有效横扫速度及Y速度，不能继续用一个速度计算整个扫描时间。

## 换算与时间

两轴分别将设定速度换算为整数RPM，界面显示各自换算结果。X、Y超时也分别计算；旧的单轴实验入口使用实际被选轴的RPM推算超时。

令行数 `N=H/h`，双向纯运动时间为 `N·W/vX + H/vY`，单向为 `2N·W/vX + H/vY`。加上启动等待、通信轮询、换轴停留和加减速才是实际总时间。这里最后一行也换Y，单向最后一行也回程。

1 mm导程下最低非零整数命令1 RPM对应0.016667 mm/s。输入0.010 mm/s会舍入到1 RPM，不代表实测10 μm/s。细分影响脉冲位移，不会绕过本协议速度字段的整数RPM限制。

分离速度能避免X提速连带Y提速，不能保证消除所有振动。当前 `SCAN_ACCELERATION=0` 表示直接按设定速度启动；未在没有实机证据的情况下擅自更改加速度。异常窜动、噪声增大或卡滞时停止运行，断电后检查接线和机械干涉，再做小行程检查。

## 验证范围

软件测试检查两轴速度独立、RPM和时间计算、不同方向与模式、通信异常停止。主机测试通过实际运动命令字节核对X120 RPM时Y仍60 RPM。它们不替代实机稳定性和位移测量。
