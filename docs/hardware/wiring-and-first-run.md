# 硬件接线与首次运行

[返回项目首页](../../README.md) · [固件编译说明](../../firmware/README.md) · [常见问题](troubleshooting.md)

## 1. 准备设备

准备 STM32F103C8T6 控制板、SWD 下载器、两台带丝杆滑台的 ZDT X42S 电机及对应动力电源。电源电压、电流与接插件按实际购买型号的手册选择。使用 RS485 版本时，还需要与 STM32 3.3 V 逻辑兼容的 TTL–RS485 模块。

本项目使用 Emm V5 命令协议，串口参数为 **115200 baud、8 数据位、无校验、1 停止位（8N1）**。确认电机的接口硬件、固件协议和通信参数均匹配。

## 2. 两轴地址和驱动器参数

| 参数 | 水平 X 轴 | 垂直 Y 轴 |
|---|---:|---:|
| 地址 | 2 | 1 |
| 电机步距角 `MotType` | 1.8° | 1.8° |
| 细分 `MStep` | 16 | 16 |
| 丝杆导程 | 1 mm/圈 | 1 mm/圈 |

两台电机在接入同一总线前分别设置地址。若两台均为出厂地址 1，先单独连接水平轴，用驱动器菜单或厂商上位机将它设为 2，确认保存后再接入垂直轴。具体地址设置入口以所用驱动器固件手册为准。

默认 `Y_AXIS_ID_SETUP_ONCE=0`，正常使用保持此值；该可选功能只把单独连接的地址 1 电机写成 `Y_AXIS_ADDR`，不会自动为两台电机分配地址。默认 Y 地址本身就是 1。

在驱动器角度显示界面按 Enter 进入菜单，用 Next 检查 `MStep` 和 `MotType`，完成后退出菜单。还需按驱动器说明确认电机处于可接收串口位置命令并能运动的状态；本扫描流程不负责执行驱动器的完整校准或使能配置。

## 3. 电机通信接线

STM32 使用 USART1：**PA9 为 TX，PA10 为 RX**。下面两种接法根据电机接口版本选择。

### RS485 版本：通过转换模块连接

```text
STM32 PA9 (TX)  → 模块的 TTL 数据输入（DI）
STM32 PA10 (RX) ← 模块的 TTL 数据输出（RO）
STM32 GND      ─ 模块 GND / 通信参考地

模块 A ─┬─ X 轴 R/A/H（A）
        └─ Y 轴 R/A/H（A）
模块 B ─┬─ X 轴 T/B/L（B）
        └─ Y 轴 T/B/L（B）
```

模块的 TX/RX 标注习惯可能不同，请按数据输入/输出方向接线；原厂配套模块图中 TX 接 PA9、RX 接 PA10。模块供电和逻辑电平按其规格连接。本代码没有 DE/RE 方向控制引脚，因此使用自动收发切换模块；需软件控制方向的模块要另行增加 GPIO 控制。

RS485 的 A/B 接至转换模块，不能直接接 STM32 的 PA9/PA10。总线两端保持相同极性，终端匹配按模块与布线条件配置。电机动力电源接各自的 V+ / GND，电机动力电压不能接入控制板逻辑引脚。

### TTL 版本：串口直连

| STM32 | 电机 TTL 接口 |
|---|---|
| PA9（TX） | R/A/H，TTL 模式下为接收端 |
| PA10（RX） | T/B/L，TTL 模式下为发送端 |
| GND | GND |

此表描述单台 TTL 电机的接线。双轴需要厂商支持的多机串口接法；不要直接并联两路普通推挽 TX 输出。复现双轴总线时可使用对应的 RS485 版本。接口形式应在购买和接线时确认。

## 4. 野火小智双 USB 板跳帽

板载 CH340 与电机通信均可能占用 PA9、PA10。按本项目接法，拔掉 J5 上的 `PA9-RXD` 和 `PA10-TXD` 跳帽，让 USART1 供电机通信使用。BOOT 跳帽保持正常从 Flash 启动的配置，不随串口跳帽一起拔除。

## 5. 下载器和控制板供电

项目使用野火 DAP 小智款，控制板通过自己的 USB 接口供电：

| DAP | STM32 |
|---|---|
| RST | NRST |
| CLK | PA14 / SWCLK |
| DIO | PA13 / SWDIO |
| GND | GND |
| 3V3 | 本接法中不接 |

若换用其他下载器，按其说明确认是否需要目标电压参考脚。Keil 下载器与 Flash 配置见[固件编译与下载](../../firmware/README.md)。

## 6. 按顺序验证

**每次更换固件都按“关闭电机动力电源 → 编译和下载 → 确认起点 → 电机上电 → 等待就绪 → 复位 STM32”操作。** 控制板可以在下载期间保持 USB 供电。

1. **通信检查**：打开 `01_COMM_CHECK_NO_MOVE.uvprojx`，Rebuild 后下载。电机上电就绪并复位控制板，两轴应不运动，PA1 红灯常亮表示两个地址均应答。本阶段没有 5 秒运动倒计时。
2. **1 mm 测试**：打开 `02_1MM_MOTION_TEST.uvprojx`，重复下载流程。复位后闪灯 5 次，X 沿方向 1 移动 1 mm，Y 沿方向 0 移动 1 mm；X 沿方向 0 返回 1 mm，Y 再移动 1 mm。最终 X 回到原侧，Y 累计移动 2 mm。
3. **10 mm 测试**：恢复测试起点，打开 `03_10MM_MOTION_TEST.uvprojx`。X 往返各 10 mm，每条后 Y 移动 2 mm，最终 Y 累计移动 4 mm。核对实际距离和速度。
4. **正式扫描**：修改 `snake_scan_config.h`，确认宽、高、行距、速度、方向和安全行程。恢复起点，打开 `04_ACTUAL_SNAKE_RUN.uvprojx`，重新编译并下载，按相同流程运行。

方向 0/1 表示电机旋转方向；实际左、右、上、下取决于安装方式。首次测试应取下易损负载，观察少量位移后再确定正式扫描起点。

## 7. 每次正式扫描前

- X 轴沿 `X_FIRST_PASS_DIRECTION` 留有完整扫描宽度，Y 轴沿 `Y_STEP_DIRECTION` 留有完整扫描高度。
- 起点与机械限位之间留有余量，线缆不会随滑台运动被拉紧。
- 确认贵重负载固定妥当，运动区域无人员或工具。
- 手边有可直接切断电机动力的开关。

扫描完成后红灯常亮。程序不会自动回零，也不会自动再循环；再次按 RESET 会从当前位置重新执行同一条路径。先恢复起点，再开始下一次扫描。
