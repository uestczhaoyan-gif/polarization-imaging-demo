# 资料来源

[返回项目首页](../../README.md) · [第三方声明](../../THIRD_PARTY_NOTICES.md)

本项目保留编译所需的第三方源码和许可证。电机手册、核心板图纸、下载器资料包与厂商接线图片可从原始资料或厂商渠道获取，发布目录不包含这些本地参考副本。

## 张大头 / ZDT

电机协议函数 `firmware/BSP/Emm_V5.c`、`Emm_V5.h` 来自张大头提供的位置模式例程。源文件中的作者与来源注释保留；中文注释转为 UTF-8，便于 GitHub 阅读。

- [张大头店铺](https://zhangdatou.taobao.com)：来自原例程的厂商地址，可联系商家获取对应产品资料与源码授权说明。
- 配套原始资料中的《ZDT_X42S 第二代闭环步进电机用户手册 V1.0.5》，文件版本日期为 2026-05-27。
- 本项目调用 Emm V5 命令；《MODBUS 协议使用说明》不能替代所用固件的 Emm 命令说明。购置相同外形产品时也要核对接口与固件。

## ST 与 Arm

`firmware/Drivers/STM32F1xx_HAL_Driver/` 保留 HAL 驱动；`firmware/Drivers/CMSIS/Include/` 与 `Device/` 提供核心和设备支持。各组件以随附许可证为准。未使用的 CMSIS DSP、NN、RTOS、示例和离线网页资料未纳入发布目录。

版本日期用于标识上游资料，不随本项目整理日期修改。更新第三方依赖时应记录新的来源、版本及验证结果。
