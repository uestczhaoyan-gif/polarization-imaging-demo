# 单向扫描与双向蛇形

双击根目录START.cmd，在“扫描模式”选择，检查预览并保存，再在Keil重新编译、下载。默认仍为双向蛇形。头文件中的 `SCAN_MODE=0` 为双向、`SCAN_MODE=1` 为单向；其他值会被拒绝。

## 路径

双向：X首方向横扫 → Y换行 → X反方向横扫 → Y换行。两个方向的横扫均用于成像。

单向：X首方向横扫 → X反方向返回 → Y换行 → 重复。仅首方向横扫用于成像；返回段原始电流应保留，但重构时排除。X首方向决定所有有效行的方向，Y方向决定换行方向，方向0/1仍不等于装配后的左右/上下。

例如宽2 mm、高1 mm、行距0.5 mm，以首方向为X正方向：

```text
双向：(0,0) → (2,0) → (2,0.5) → (0,0.5) → (0,1)
单向：(0,0) → (2,0) → (0,0) → (0,0.5)
           → (2,0.5) → (0,0.5) → (0,1)
```

两种模式均为高度/行距条有效扫描线，最后一条后仍换行一次，最终Y等于设置高度。单向最后一行也返回，最终名义X=0；双向偶数行X=0，奇数行X=宽度。最终Y处没有额外横扫。

返回使用同一速度、加速度、到位检查和换轴等待。返回失败立即进入现有停止流程，红灯错误码8；有效X扫描失败为3，Y换行失败为4。通讯检查工程不运动，1 mm和10 mm测试工程采用固定范围，但同样遵循所选扫描模式。

## 时间与实际位置

设N=高度/行距，宽度W、高度H、换算后的实际命令线速度v：

- 双向纯运动时间：(N×W+H)/v。
- 单向纯运动时间：(2×N×W+H)/v，包含最后一行返回。

单位统一使用mm、mm/s，结果为秒。单向80×80 mm、行距2 mm、2 mm/s，纯运动约54分钟；双向约27.33分钟。另加启动、状态查询、每次移动后的300 ms等待和加减速。界面估算不替代测量时间记录。

当前返回是发送等距离、反方向的相对运动指令，名义坐标归零不证明机械位置精确复原；没有机械回零、预行程、绝对坐标闭环或回差标定。单向可统一有效扫描方向，不能保证消除回差或修复偶发快速横移。上一轮规划的预行程、目标坐标改造和事件同步属于后续独立改动；本版不自动越过用户设置范围。

## 采集与重构

模式切换只改变STM32路径，不会切换源表测量，也不会自动修改Python重构配置。现有实测案例仍使用原来的双向路径，不修改历史结果。

单向数据不要直接套用估计蛇形分行或常规相邻行反转：应使用 `time_windows` 或 `index_windows`，为每条有效横扫指定独立的start/stop窗口，并为所有行填写相同的 `direction`（forward或reverse，取决于希望显示的X轴方向）。排除返回、Y换行和等待区间。格式见[重构配置](../reconstruction/configuration.md)。尚未实现电机事件时间记录；没有准确窗口时不能宣称已精确定位每行。

首次烧录按通信检查、小范围测试、正式扫描逐步核对方向、返回、换行及终点。通过主机模拟和软件测试不等于Keil目标编译、烧录或实机验证。

旧版头文件没有SCAN_MODE，新界面会拒绝读取；请保留完整旧版备份，在新版界面重新输入原毫米参数，不要只拿旧头文件覆盖新版。
