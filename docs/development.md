# 开发与扩展

## 当前边界

这是离线、单通道、等宽水平行且固定行距的重构例程。每像素归约器为原始电流中位数，二值化为一个全局阈值。时间窗模式处理不均匀采样，但要求窗内匀速；目前不支持非匀速编码器轨迹、任意 Y 坐标、空像素掩码、自动背景扣除或多通道偏振参数。

## 分层接口

```python
from pathlib import Path
from snake_scan.pipeline import reconstruct
from snake_scan.report import write_outputs

data = reconstruct(Path('examples/synthetic/config.json'))
print(data['binary'].shape)
write_outputs(data, Path('outputs/my_run'))
```

- `load_measurements`：把仪器文件转为原始电流、点号、可选时间戳及来源信息。新增仪器格式时在这一层转换，不能静默忽略坏行或改写顺序。
- `build_edges`：把扫描记录转为每行每像素的原始下标边界及扫描方向。返回形状 `(rows, columns+1)` 的边界数组。所有区间半开，不重叠。
- `aggregate`：把区间内原始点归约成中位数等统计量，同时保存 `limits`、`sample_row`、`sample_col`。新增均值/稳健估计器时保留原始数据，另存选择的归约规则。
- `write_outputs`：生成审计表、静态图和自包含查看器。NPZ 用 `allow_pickle=False` 读；元数据为 JSON 字符串。
- `viewer.html`：只显示已有映射与阈值探索，不在浏览器里重新拟合扫描轨迹。

## 建议扩展顺序

1. **仪器时间戳与运动事件导出**：把实际每行有效横扫转换为 rows.csv，即可使用现有时间窗接口。这比先添加复杂图像修补更直接。
2. **编码器位置映射**：将同步后位置轨迹映射到各 X 网格边界，并检查单调性、回差/暂停、时间偏移与外推。若一个像素对应多个不连续区间，需要升级 `limits` 为区间列表，并同步修改反查表与查看器，不能继续假设 `[a,b)` 一段。
3. **缺失掩码**：空像素应有独立 valid mask，与低电平 0 区分。需同步修改聚合、NPZ、CSV、着色和测试。
4. **多通道/偏振态**：保存通道与角度、原始参考和空间配准。先检查共用轨迹/独立扫描的时间空间对应，再在连续电流图基础上计算偏振量，不直接用二值矩阵作定量。
5. **背景校正**：保存暗场和透光参考的时间、配置及校正方法。保留未校正结果；不能把样品真实阴影当背景扣除。

## 验证

```bash
python -m unittest discover -s tests -v
```

测试覆盖：正反向与反查、空像素/窗口重叠拒绝、非均匀时间戳按时间分箱、半开时间边界与等待剔除、长采样间断、显式方向、坏点号/时间戳/NaN、合成已知答案、短八进制记录与单行映射、HTML 数据转义。

已知答案与映射测试保证按给定参数处理一致，不能证明估计轨迹等于真实运动。发布前本机另用浏览器实际点击测试二维图→曲线、曲线→像素、未使用点提示、阈值/恢复、CSV 导出，以及 360/736/1280 像素宽度的布局。合成时间戳例子检查 I–t 切换。

CI 在 Windows/Ubuntu 和 Python 3.10/3.12 上运行 Python 测试及合成例子。依赖下限写在 pyproject.toml，实际 Python/NumPy/SciPy 版本写入输出 metadata；更换库可能改变自动优化的微小数值，正式测量应保留已确认的行边界与结果。

## 文件管理

`outputs/`、`local/`、缓存和构建目录被 Git 忽略。自带数据由脚本生成，仅用于软件验证。每次重要实验单独保存 config 和 outputs；命令行默认拒绝覆盖非空输出，例子快捷脚本明确使用 `--overwrite`。

MIT 许可覆盖代码与仓库内示例。不要把第三方仪器整本手册或不属于自己的数据直接复制到仓库；文档引用使用官方页面链接。
