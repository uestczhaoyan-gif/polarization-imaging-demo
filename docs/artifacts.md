# 不规则像素诊断

二维重构与照片不完全一致，可能来自实际光学遮挡、光斑大小、倾斜样品、像素网格、运动/采样同步误差，以及仪器或环境波动。不能只凭结果图把这些都叫作噪点。

## 用联动查看器判断

- 像素内连续地从高电流过渡到低电流：可能跨过真实边缘；一个像素混合了透光和遮光区。
- 像素内反复上下波动：检查环境光、光源、机械振动、量程和仪器状态，需要对照测量才能区分。
- 像素内电流平稳却出现在预想之外的位置：优先查扫描行边界、周期、起点、方向和真实遮挡。
- 相邻正反向行左右交错：检查双向时延、回差和方向记录。
- 越往后越偏：检查行周期误差、采样间隔变化或时钟漂移。

这些是检查线索，不是确诊。高电流采样占比接近 0.5 表示混合，不是错误概率。修改阈值、起点和周期后比较变化比例时，要固定其他参数并注明是否重新拟合；变化比例不是正确率。

## 怎么减少伪影

记录每点时间戳与每行有效运动窗口；固定光路和环境；保存暗场与透光参考；用已知直边做正反向和重复扫描，检验光斑与实际空间分辨率。

行距和横向分箱会使倾斜边缘阶梯化。增加输出像素数不会自动改善真实分辨率；光斑大小和积分期间的运动距离也会平均边缘。积分时间影响噪声与读数速度，完整采样还可能有其他开销；参见 [Tektronix/Keithley 官方 NPLC 说明](https://www.tek.com/en/support/faqs/speed-what-nplc)。

正式结果应保留原始矩阵、原始曲线、参数和映射。展示用平滑、补洞或去孤点若确实需要，应另存派生图，不能覆盖测量证据。
