# 参与项目

欢迎报告复现问题、改进文档或扩展扫描功能。

## 报告问题

在 GitHub Issues 中写清楚：硬件型号、接口版本、驱动器固件、所用 Keil 工程、参数改动、期望动作、实际动作和红灯错误码。必要时附自己的接线照片。已有排错入口见[常见问题](../hardware/troubleshooting.md)。

## 提交修改

1. Fork 仓库并创建说明用途的分支，例如 `docs/wiring-guide`。
2. 修改代码时同步更新相关参数和使用文档。
3. 检查改动清单，只提交源码、文档与有权发布的必要图片。编译输出、个人配置及本地厂商资料由 `.gitignore` 排除。
4. 涉及运动逻辑、方向、距离或速度的修改，依次完成通信、1 mm、10 mm 与目标范围验证，并记录硬件、导程、细分及实际结果。
5. 提交 Pull Request，说明问题、修改后的行为和验证情况。尚未进行的测试明确写为未验证。

通信超时、查询重试和故障停止机制的变更需要说明原因及实机结果。验证记录格式见[验证记录](../hardware/validation.md)。
