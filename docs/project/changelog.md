## 1.0.0（发布准备）

整理日期：2026-09-08。实际 GitHub Release 日期以发布记录为准。

- 提供基于 STM32F103C8T6 与 ZDT Emm V5 命令的双轴蛇形扫描控制。
- 提供通信检查、1 mm 测试、10 mm 测试和正式扫描四个 Keil 工程。
- 集中配置扫描宽度、高度、行距、方向和速度，支持奇数与偶数条水平线。
- 提供 UART/DMA 接收恢复、状态查询重试、到位轮询和错误灯提示。
- 使用 `stm32-zdt-xy-stage` 仓库名称，固件统一位于 `firmware/`。
- 补充接线、编译下载、扫描路径、故障排查与 GitHub 上传指南。
- 发布目录仅保留固件依赖，排除个人 IDE 配置与本地参考资料；项目中文源码注释采用 UTF-8。

验证状态见[验证记录](../hardware/validation.md)。
