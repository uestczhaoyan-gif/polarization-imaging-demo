# 实际测量与数据保存

单向扫描需额外记录扫描模式、有效扫描方向、每行有效开始/结束时间、返回区间及最终返回/换行规则。不要把返回段或Y移动段当成成像行；所有有效行使用同一方向。[扫描模式说明](../hardware/scan-modes.md)。

目标是能明确回答：**某个原始电流点是在什么时候、哪个位置、什么仪器设置下取得的？** 保存图片之外，还要保存可以重新计算图片的数据与运动记录。

## 实验前

1. 固定样品、光源、探测器和光路；标出 X/Y 正方向、起点和样品朝向。拍安装照片，记录玻璃、胶带、导轨等实际遮挡。
2. 测光斑/有效探测区域大小。先扫直边或已知宽度的遮挡，检查空间过渡宽度，再选择行距、速度和输出像素尺寸。
3. 在同一源表设置下采集暗场和无遮挡透光参考，记录均值、波动和漂移。参考不稳定时先解决光源、机械或读数问题。
4. 确认源表没有量程溢出/合规限制等异常；记录型号、固件、测量量程及是否自动、源输出模式/幅值、积分设置及单位、自动归零、滤波、触发和缓存方式。
5. 先做短扫描：正反各一行，验证方向、启动延迟、实际有效横扫用时、换行等待和采样点数。不要仅由面板刷新值推断采样率。
6. 选择时钟与同步办法。优先保存仪器自带测量时间戳，并使用能在运动和测量记录中共同识别的触发事件；两个时钟需记录偏移、同步事件和必要的漂移校正。

## 扫描中

- 原始采集先启动，运动后启动是可以的。把等待数据保留，另外保存电机启动事件，不需要人为删除开头数据。
- 每行记录行号、方向、目标 Y、有效 X 横扫开始与结束时刻；区分“发出命令”“开始运动”“进入匀速”“到位”四类事件。
- 水平扫描期间保留原始电流、时间戳和状态；垂直步进、转向等待也可以持续采集，但必须在运动日志中能够区分。
- 尽量使用固定、可复现的扫描参数。手动停止也可以，但要立即记录停止时刻、实际完成行数和最后一行是否完整。
- 若改量程、滤波、光源、偏振角或手动干预，写事件日志；不要让参数改变无记录地混入同一段。
- 记录超时、掉线、到位失败、合规/过载、缓冲溢出及丢点，不静默重编号来掩盖缺失。

## 扫描后

1. 保存原始导出文件，并额外转换成开放 CSV。原文件不覆盖，注明转换脚本版本与单位。
2. 保存此次实际使用的电机固件版本/提交号与参数；计划值和实际执行值分开记录。
3. 检查点号连续性、时间戳递增性、间隔分布、完整行数和末行状态。画完整 I–point/I–t，先确认有没有明显采集中断。
4. 再测一次暗场和透光参考，判断漂移。最好重复一次同方向扫描或改变起始方向，区分固定样品轮廓与扫描伪影。
5. 为实验建立唯一文件夹，保存参数、原始数据、日志、参考、照片、重构配置和结果。不要只留最终 PNG。

## 建议保存的文件与字段

| 文件 | 最少字段 | 为什么有用 |
|---|---|---|
| `measurements.csv` | `point,time_s,current_A` | 每个原始点的真实时间、电流和顺序 |
| `rows.csv` | `start_s,stop_s,direction` | 本程序可直接使用的有效匀速横扫窗口 |
| `motion_log.csv` | `event_time_s,row,event,x_mm,y_mm,direction,status` | 区分发命令、运动、匀速、到位、换行与停止；最好有反馈位置 |
| `instrument_log.csv` | 时间、量程、合规/过载标志、触发号等仪器状态 | 判断异常读数和采样间断来源 |
| `experiment.json` | 几何、运动、仪器、环境、同步参数 | 解释和复现实验；模板见下 |
| `dark.csv`、`bright.csv` | 电流、时间戳、参考条件 | 暗场/透光参考与漂移检查 |
| 原文件与安装照片 | 原始导出、样品朝向、正向箭头 | 避免转换丢信息；解释真实遮挡 |

`rows.csv` 是有效横扫窗口，不是完整运动日志。现版程序按每行相同宽度和固定行距放置像素，`motion_log.csv`/参考文件不会自动参与重构；它们用于审计和后续扩展。若一行有明显加减速或非匀速段，应重新规划稳定横扫范围，或扩展位置反馈映射；不能把整段硬塞进匀速模型。

时间戳还应注明代表积分开始、中心、结束还是主机接收时刻；接口批量读数时，主机收到一包的时间不能代替包内每点测量时间。稳定的固定延迟和随时间漂移需分别处理。

## 参数怎么选

- 横向像素宽 `Δx = 扫描宽度 / columns`；垂直间距为实际行距。二者应与光斑及目标细节相匹配。
- 匀速/等间隔采样下，每个横向像素点数约 `Δx / (速度 × 采样间隔)`。先用实测时间戳算采样间隔，再检查每像素是否有足够有效点。
- 积分期间运动距离约 `速度 × 积分时间`。增加积分可减少某些噪声，但也会增加运动平均、影响采样速度。结合光斑和像素尺寸选择，再用直边试扫验证。
- NPLC 不是采样间隔。例如 50 Hz 工频下 0.1 NPLC 为约 2 ms 的积分，完整读数还可能含归零、量程、源延迟和通信开销。[官方 NPLC 说明](https://www.tek.com/en/support/faqs/speed-what-nplc)、[Keithley 6430 官方手册关于源延迟—测量周期的说明](https://www.tek.com/-/media/files/6430_901_01Dnl.pdf)。本次源表型号未知，这些说明不构成对具体界面“0.1”单位的确认。
- 若后续做偏振定量，需保存每个偏振态/通道的角度、标定、参考和统一空间坐标。不同角度分别扫描时，还需检验重复定位与光源漂移；当前二值图仅用于演示遮挡。

最小可行改进：**每点时间戳 + 每行有效运动起止/方向 + 完整参数快照**。这三项通常比分辨率很高但没有运动记录的一张结果图更有用。
