# 不规则像素从哪里来

## 先分清“和照片不一样”与“程序算错”

照片显示样品的外观；扫描记录的是光斑沿轨迹经过样品时的光电流。二者还隔着光斑尺寸、胶带透光性、实际姿态、导轨遮挡、扫描位置和采样积分。照片没有经过坐标标定，不能直接逐像素作为真实标签。

本例原始电流 120,311 点，估计完整行 29 条，每行 50 像素，每像素 77 或 78 点。低电流中位数约 3.7 μA，高电流约 23.5 μA，二值阈值 12 μA。分行周期约 4015.033 点，首条选定完整周期起点约 1792.087；实际首个建图采样为 1855。点号均按连续十进制显示。

用户补充启动前约等 10 秒。开头约 13.6 μA 的平稳段在 point 850 左右首次持续变化，与启动过程相容，但不是硬件触发证据。point 0～1854 已整体不参与建图，不能把这一整段都当成静止等待，更不能再次裁剪“10 秒”。

## 这份数据支持哪些判断

| 观察 | 实际数值 | 能说明什么 |
|---|---|---|
| 阈值改到 8 μA | 12/1450 个像素变化，约 0.83% | 在该范围内，大部分像素分类稳定 |
| 阈值改到 16 μA | 9/1450 个像素变化，约 0.62% | 不能把主要形变都归因于阈值 |
| 每行周期改变 ±8 点 | 各约 8.41% 像素变化 | 对齐误差沿行数积累，形状对它更敏感 |
| 换行占比从 3.1% 改到 0 / 5% | 约 2.55% / 1.66% 像素变化 | 转向时间模型也会改变边缘 |
| 高采样占比在 20%～80% | 46/1450 个像素，约 3.17% | 像素内部确有混合电平；不等于这 46 个都错 |
| 内部像素四邻居全部反色 | 0 个 | 可见不规则更偏向边缘台阶、凸出和局部错位，而非此定义下的孤立单点 |

上述敏感性比较保持其他参数不变，不分别重新拟合；变化比例不是正确率，也不证明原模型是唯一解。记录见 [sensitivity.json](../../experiments/tape-z/reference/sensitivity.json)。

在项目根目录运行 `python experiments/tape-z/analyze.py` 可重新计算这些统计，结果保存到 `local/reconstruction/tape-z/analysis.json`。

用名义宽度做量级估计：有效横扫约 4015×0.969≈3891 点，8 点相当于每行约 0.21 mm 的相位变化；经过 28 个间隔可积累到约 5.8 mm。这里用的是恒定采样/速度假设，仅用来解释为何“单行很小的误差”会影响后面的轮廓。

## 在查看器里实际检查两个像素

行列号从 0 开始，在上方输入即可。

| 像素 | 原始采样 | 中位数 | 高采样占比 | 读图要点 |
|---|---|---|---|---|
| `(7,41)` | 30583～30659，共 77 点 | 12.4 μA | 50.65% | 边界像素靠近阈值，少量位置偏移就可能变色 |
| `(12,24)` | 51903～51980，共 78 点 | 3.69 μA | 0% | 平稳低电流区；若空间位置看起来不对，应优先查行映射或真实遮挡 |

先看“该像素全部原始点”：

- 如果前半高、后半低且有连续跳变，更像光斑越过边缘；中位数把混合区强制分成一个颜色。
- 如果不断上下跳动，再检查灯光、仪器设置、量程变化和机械振动。原始曲线能显示波动，但不能单独区分它们。
- 如果整段都很平稳，却与预想位置不一致，单纯平滑电流通常无用；应核对奇偶行方向、周期、起点、转向窗口及导轨遮挡。
- 若每隔一行轮廓左右交错，优先考虑正反向时延差、机械回差或方向处理；若越往后越偏，优先考虑周期误差或采样时钟漂移。

最后两条是诊断线索，不是对本次机械问题的确诊。

## 可能原因与改进办法

### 1. 没有同步，行边界是估计

原始数据没有时间戳、行触发和准确行数。当前方法通过重复结构和相邻行一致性估计固定周期；实际扫描若有变速、不同到位查询延迟或非均匀采样，同一个点号长度就不一定代表相同距离。

改进：记录每行有效横扫的真实时间边界；同步电流与运动时钟。只有发送命令的时间，不能代替电机实际开始移动时间。更进一步使用编码器位置触发或位置反馈作重采样，参见 [NI-Motion 官方手册关于位置断点触发采集的示例](https://download.ni.com/support/motion/Manuals/NI-Motion%20User%20Manual.pdf)。本例尚未实现位置轨迹插值。

### 2. 像素网格与光斑使边缘混合

2 mm 行距会把倾斜边缘显示成阶梯；横向也按 2 mm 分箱。光斑同时覆盖胶带和透光区时，测得的是二者共同影响的电流。77 个采样聚合为一个像素并不意味着该像素内照明完全相同。

改进：测光斑尺寸，做直边扫描确定边缘过渡宽度；按目标细节合理减小行距和横向分箱宽度。不要只增加输出列数，那只会减少每像素点数，不能凭空增加光学细节。

### 3. 环境光与源表设置

没关灯可能抬高背景或带来波动，但恒定背景未必导致乱点。此次高低电流间距较大、阈值敏感性小，没有证据证明环境光是主要形变原因。还需暗场、透光参考及同一设置下的重复扫描来比较。

积分时间影响速度与噪声折中；积分时间与完整采样间隔不同。NPLC 的单位是工频周期，不能把界面的“0.1”直接当作 0.1 s。积分时间过长，运动时也会增加空间平均，量级约为 `速度 × 积分时间`。请依据具体源表型号核对设置；[Tektronix / Keithley 官方 NPLC 说明](https://www.tek.com/en/support/faqs/speed-what-nplc)解释了积分与工频噪声的关系。

改进：固定光路与环境条件；记录 NPLC/积分秒数、自动归零、量程、滤波和触发设置。不要为追求速度而盲目关闭校准功能，应测量并记录完整采样间隔。

### 4. 真实遮挡、姿态与机械效应

胶带不完全水平会产生倾斜边缘，导轨/I 重叠会产生额外遮挡；这些不应作为“噪点”删除。机械回差、振动、未等待稳定和正反向差异也可能影响边缘，但本次没有位置反馈，不能分别量化。

改进：拍清楚扫描时的安装方向，记录起点/正向箭头和导轨位置。先用已知直边做正扫、反扫及重复扫描，检查是否有系统性偏移。

## 这次不采用哪些修图步骤

没有依据照片补画 Z，没有去孤点、补洞、形态学开闭操作或逐行自由拉伸。它们可能让演示更像字母，却会弱化“每个像素都能追到真实电流”的证据。若后续确需展示用平滑，请单独导出为派生图，并同时保存未经修形的矩阵和处理参数。
