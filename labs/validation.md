## v3.3.0 基础工具

2026-09-28：软件验证记录，**不是实际平移台测试报告**。

- Python 共 32 项测试，覆盖既有重构/配置、新参数预设、独立工程、日志帧/缺失/中断拒绝、时钟映射、排除空返与 Y 换行、实测表判据。串口收集器使用假的串口对象验证完成/退出，测试不连接实物。
- 主机 C 测试直接提取生产 `SnakeScan` 和 `Lab_AxisTest`，覆盖两种扫描模式、两轴、正反方向、有限次数和逐段失败退出；实际 `lab_io.c` 用模拟寄存器测试启动门控、ISR 到位时间保留、队列溢出、发送失败、接收溢出和停止请求。

- GCC Arm Embedded 编译并链接真实工程 C 源码，组合为（实验/阶段）0/0、0/3、1/1、1/3、2/3、3/3。使用 Cortex-M3、64 KB Flash、20 KB RAM 的测试链接脚本，并预留 2 KB 运行空间。测试用 GCC 启动文件和运行库适配，不替代用户的 Keil Compiler 5 构建。
