# 实验一：单向 / 双向扫描

先读 [共用接线与操作](../README.md)，双击本目录 `START.cmd`。

`扫描模式=0`：X 正扫、Y 步进、X 反扫、Y 步进，往返均成像。

`扫描模式=1`：X 正扫、X 空返、Y 步进，重复。仅正扫成像，空返速度与扫描速度相同。最后一行也空返并步进，终点为名义 X=0、Y=扫描高度；最后一条成像线在“高度−行距”。回到起点是相对位移返回，不是传感器回零。

## 对照实验

保持样品、光斑、起点、宽高、行距、有效横扫速度、源表设置不变，分别测双向和单向，至少各 3 次，交替实验顺序。观察同一竖边在相邻行的横向偏差，报告各次结果而不是只选最好的一幅。若只有双向的奇偶行错位明显，支持方向相关误差；单向仍可能有回程间隙、起步延迟与运动异常，不能保证更准。

建议两组都开启“电脑日志=1”，按实验二记事件再重构。单向的数据不能仍按等周期、奇偶反转处理；只使用有效 X 正扫窗口，其余时间丢弃。没有日志模块时可先运行默认小范围验证运动顺序，但完整成像仍需可靠分行。

理想运动时间：行数 N=高度/行距。双向约 `(N×宽度+高度)/速度`；单向约 `(2N×宽度+高度)/速度`。另加倒计时、每段状态确认、换轴等待和加减速时间。
