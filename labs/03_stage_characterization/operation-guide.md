# 平台三项测试：设置、测量与操作

只测最小有效位移、最低平稳速度、最高平稳速度。**默认离线自动运行，不需要 USB转TTL、电脑输入 g 或源表。** 保留现有 DAP下载、开发板供电、TTL转RS485接电机的连接即可。

## 不必转满一圈

设导程 L mm/圈，一圈指令脉冲数 P=整步数×细分数。发送 n 个脉冲，名义转角 `360n/P` 度，直线位移 `nL/P` mm。可只转很小的角度，但角度由整数脉冲离散实现。

默认 L=1 mm、P=200×16=3200：一脉冲为0.1125°、0.3125 μm。本测试直接发送脉冲，支持到一脉冲；这是指令刻度，不是实测精度。导程、细分须与实物一致。常规成像扫描界面的整数微米配置不随之改变。

## 设置

双击本目录 `START.cmd`，下拉选择三项之一。填写测试轴、方向、可用行程，生成独立工程。切换测试会载入相应默认档位，可修改列表（最多16档）。界面位移用 mm、速度用 mm/s，生成时转换成整数脉冲/RPM；不能精确表示的位移和取整后重复的速度档会被拒绝。

| 项目 | 默认档位 | 每档执行 |
|---|---|---|
| 最小有效位移 | 100、50、20、10、5、2.5、1.25、0.625、0.3125 μm | 同向预走0.2 mm → 连续3个同向小步 → 返回；速度1 mm/s |
| 最低平稳速度 | 输入1、0.5、0.2、0.1、0.05、0.02 mm/s | 单程1 mm，往返3次；末档实际指令约0.016667 mm/s |
| 最高平稳速度 | 输入1、2、3、4、5 mm/s | 单程10 mm，往返3次；先确认行程余量 |

默认每次运动后停留5秒、档间准备5秒，可增加到60秒或录像后读数。档位只是初筛，不是已验证能力。速度按 `RPM×导程/60` 实现，记录生成表中的实际指令值。固定负载、安装、供电、润滑和加速度，X/Y分开测试。

新文件夹包含完整 Keil 工程、`prepared-config.json` 参数/实际脉冲/RPM/耗时估计、`measurement-plan.csv` 空白测量表，以及生成的 `firmware/Core/Inc/lab_sweep_config.h` 分档表。更改档位、细分、导程或次数后重新生成，不要局部修改旧表。

## 编译与运行

1. 填写 [试验条件模板](trial-record-template.json)，记录量具、负载、供电、轴和代码版本；核对起点、紧固、线缆及余量。
2. 用新文件夹的 `firmware/MDK-ARM/01_COMM_CHECK_NO_MOVE.uvprojx` 编译下载检查通信，它不运动。
3. 用 `02_1MM_MOTION_TEST.uvprojx` 做固定小范围扫描确认方向。`03_10MM_MOTION_TEST.uvprojx` 也是固定范围扫描，按需使用。**检查工程会动两轴，不执行分档表，即使正式实验只选X轴。**
4. 打开同文件夹的 `04_ACTUAL_SNAKE_RUN.uvprojx`，Rebuild并下载。正式实验只动选定轴。沿用驱动器 Receive/Both 接受应答设置。
5. 准备量具和录像；电机供电就绪后复位STM32，通信检查及倒计时后自动执行一轮全部档位，不用接日志口。
6. 每档开始红灯短闪 k 次表示第 k 档，再等待档间准备时间。**每次运动后的测量停留期间红灯亮，停留结束熄灭。**全程完成后持续常亮；故障时停止并重复闪错误码（分档位移失败为10），不继续下一档。
7. 发生突跳、明显卡顿或异常声音，立即中止并记录档位。离线模式没有电脑停止指令，使用电机电源开关停止；不要用会重新启动实验的复位键代替急停，也不要带电拔电机线。通信检测不能保证发现机械异常。

完成后是名义相对返回，不是机械回零；再运行前确认真实位置。日志设为1才需要按 [实验二](../02_motion_timing/README.md) 接线并输入g；离线默认不需要。

## 最小有效位移怎么测

1. 使用分辨率足够的量具或标定相机测实际直线位移；指令数、电机编码器不代替滑台位置。1 μm分辨率的量具不能证实0.3125 μm小步。
2. 每档先同向预走0.2 mm，停留灯亮时记基准读数 p0。预走建立同向接近条件；若不足以克服回差，应增加预走量并保留行程余量。
3. 每次小步后灯亮，依次记 p1、p2、p3，分别算 `p1−p0、p2−p1、p3−p2`。去程统一为坐标正方向。不要只看累计位移就声称每个小步都发生。
4. 选能可靠分辨、每步稳定且满足预先规定误差容差的最小档。边界附近把每档步数增至10并独立重复多轮，仍属于这个实验。
5. 看不清时记“测量能力不足”，不能记“电机没动”。最小档通过仅表示已达到当前测试/指令下限。

## 最低与最高平稳速度怎么测

固定单程距离和其他条件，自动逐档往返。低速观察停滞、爬行；高速观察突跳、卡顿、明显振动及异常声音。观察整段并录像，不只看到达终点；低速可用量具/视频时间序列辅助判断是否连续运动。

在每段确实完成且人工判定平稳的档位中，取最低/最高通过的**指令速度**。它不是独立测速结果，也不证明瞬时速度完全不变。最高档仍通过时只能报告“已测到该档”；另设有限档位进一步寻找边界。临界档增加重复次数，不能发生异常后继续自动提速。

## 填表与可选汇总

复制 `measurement-plan.csv` 为 `measurements.csv`。不要改计划列。完成的段填 `completed_yes_no=yes`，未执行留空；观察后填 `stable_yes_no=yes/no` 和 notes。位移测试填写 `measured_position_mm`，尤其是 preload 和每个 step；速度测试可不填位置。

在生成工程根目录运行，位移示例：

```powershell
python tools/analyze_sweep.py --project . --measurements measurements.csv --resolution-mm 0.001 --tolerance-mm 0.002 --output report.json
```

分辨率与容差换成真实值。筛选要求每个实际小步大于量具分辨率的两倍，且在误差容差内；它不替代校准或完整不确定度评定。

速度测试：

```powershell
python tools/analyze_sweep.py --project . --measurements measurements.csv --output report.json
```

程序只汇总你的测量与观察，留空或未完成不算通过，不自动感知机械状态。旧版固定单档模式和 `analyze_stage.py` 仅保留兼容，本次使用 `analyze_sweep.py`。
