# 实验三：小位移、重复性和最高已验证平稳速度

先读 [共用操作](../README.md)。双击本目录 `START.cmd`。选轴、方向、速度、每次距离、次数和停留时间，生成独立工程。**只有 04 工程执行以下测试**。每次复制并填写 [试验条件模板](trial-record-template.json)，与日志保存在一起。

- 实验=2：同一轴前进 d、停留、返回 d、停留，重复 N 次。用于重复定位、回程误差和速度试验；完成后名义位置回到 0。
- 实验=3：同一轴连续同向走 d、停留，共 N 次，再一次返回 N×d。用于小位移阶梯测试。总行程 N×d 必须在当前可用行程内。

两种模式均等待电脑 `g`。一次只测试一个轴、一个速度档，不会自动提速。停留默认 5 秒，可设到 60 秒；测量来不及时录像，按事件编号回读，或增加停留。重复测试前确认真实位置，名义返回不是机械回零。

## A. 先建立测量能力

需要百分表/千分表、已标定相机等独立位移测量。记录量具分辨率、校准和安装方向。建议测量分辨率明显小于待判定误差（例如 ≤ 容差的 1/5）；分辨率不等于测量准确度。不要仅看驱动器编码器或指令脉冲就宣称滑台达到微米精度。

默认 1 mm 导程、200 整步/圈、16 细分时，一个指令脉冲对应 0.0003125 mm。但微步不保证每步机械位移均匀；本整数微米配置的最小精确网格是 0.005 mm，界面可输入它。实际最小可分辨位移还受负载、静摩擦、回程间隙及量具影响。测试 5 μm 需要相应测量能力。

## B. 小位移和重复性

1. 固定低速与安装负载，先 1 mm 往返 3～10 次，检查是否回到实测零点，排除松动/卡滞。
2. 阶梯模式试 0.1、0.05、0.02、0.01、0.005 mm；这些是候选档，不是已验证精度。每档重复多轮，记录各步实测绝对位置，再求相邻位置差。没有明显超过测量不确定度的实际位移，就不能把那档称为可分辨步距。
3. 用往返模式重复同一目标位置。报告平均偏差、最大绝对误差、同方向重复位置标准差及极差；X/Y 分开。阶梯一次访问的每个位置不足以计算重复性，要多轮重复。

## C. 最高平稳速度

先确认紧固、润滑和线缆无异常。保持同一轴、负载、行程和加速度，只改速度。可从已正常的 1、2 mm/s 开始，之后小幅增加；不要直接跳到协议上限。先短行程验证方向，再在有充分余量的代表性行程上测量每档至少 3 次往返。临界档增加到至少 10 次，并补代表性长时间扫描。设置适当加速度时也要记录；不同加速度测试结果不能直接合并。

每段观察并录像：是否有突跳、卡顿、声音异常、漏行、位置偏差。观察到突然加速即该档失败，即使最终回到目标；均值速度和终点误差都不能单独证明匀速。最好从视频/位移传感器取中间位置随时间曲线。软件没有直线传感器，不自动判断轨迹是否平稳。

报告“在某负载/行程/加速度/判据下，最高**已测试通过**速度”。如果最高档也通过，只能说明上界尚未测出。程序允许的 1～3000 RPM 是协议限制，不是此平台安全速度。指令实际线速度 `RPM×导程(mm)/60`，RPM 取整会导致输入值与实际指令略有差别。

## 生成与分析实测表

保存完整日志后，在包根目录执行：

```powershell
python tools/analyze_stage.py --events local/run01/events.csv --sheet local/run01/measurements.csv
```

填 `measured_mm`（相对起始实测零点的位置；去程方向定正）、`stable_yes_no`（逐段观察 yes/no）、`notes`。`measured_motion_s` 可填独立测量的实际运动时长，不填软件 MOVE_END 的时间差冒充匀速段运动时长。命令位置由日志生成，不要修改。

```powershell
python tools/analyze_stage.py --events local/run01/events.csv --sheet local/run01/measurements.csv --resolution-mm 0.001 --tolerance-mm 0.01 --report local/run01/report.json
```

分辨率、容差替换成你实际量具与预先确定的判据。空白、未完成或报错日志不算通过。往返至少 3 次且所有运动被人工判定平稳、位置误差不超过容差，才标记该次速度试验通过。阶梯试验只输出位移误差，不作为速度通过证明。

不同速度的报告请配合实验表逐档比较；不自动混合不同轴/负载的结果。保存失败试验同样重要，它能给出条件边界。第三组测试所得是实验结果，不是厂家额定参数。
