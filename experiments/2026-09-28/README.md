五个平行案例保存原始电流、配置、估计行窗口、静态图与交互结果。原始数据只复制，不改写。运动参数测试文件夹未纳入本次公开数据。

先打开 [实验图集 index.html](index.html)，再进入各组交互图。[一页PPT文字/实验](slide-notes.md)可直接用于整理汇报。[参数总表](experiment-summary.csv)便于对照。图集和查看器可离线打开，不需要 Python。

## 核心处理：四步

1. **读完整电流序列。** `.xls`实际是两列文本，单位A、点号为八进制显示。按原始顺序解析，验证点号连续；不插值补点，不删除尖峰。完整I–point图包含等待、回程、换行与尾部记录。
2. **估计哪些点属于横扫。** 重复出现的远端宽电流平台作为分行锚点。双向模式每两行出现一次，单向模式每行一次。锚点来自电流，不是驱动器到位信号。用秒表平均行时长和名义X行程时间分配横扫/停留，锚点之间线性映射到点号。允许周期点数随段落变化。
3. **一行分成像素。** 各横扫窗口等分为列，逐格取其中全部原始电流的中位数。双向反向行翻转列顺序；单向只保留正向横扫，回程排除。默认横向像素格距等于Y行距，保证可比的方形名义网格。
4. **连续颜色表示电流。** 不设阈值、不二值化、不做图像平滑或照片模板配准。普通四组统一0–650 μA，梯度组0–1450 μA。所有像素可反查原始点；格距不是实测空间分辨率。

最关键代码是 [rebuild.py](rebuild.py) 的 `prepare_windows`，以及公共 `pipeline.py` 的 `aggregate`。绘图、HTML和导出表格与核心计算分开。

## 分行依据和不确定性

锚点数值冻结在每组 `config.json` 的 `turnaround_anchor_source_indices`，完整窗口在 `estimated-row-windows.csv`。初选时用灰度开运算去掉窄脉冲，再对宽平台用11点均值及峰宽中心定位；这些操作只找锚点，未修改成像电流。开运算窗口分别为800点（0.5 mm、1 mm/s）、216点（0.5 mm、10 mm/s）、221点（1 mm、10 mm/s）、2412点（单向）、387点（梯度）。峰突出度15 μA，最小间距依各组周期设置。它们是本次经验参数，不是通用传感器阈值。

慢速50 mm组第45号锚点被尾部波动干扰，采用邻点中间值。单向和梯度最后一个锚点分别用前六/前三个间隔外推；每组配置记录了审核说明。编号从0开始。其余末端锚点即使能检出，也因样品外持续透光而证据更弱。

假设包括横扫内匀速、每对行内近似均匀采样、平均开销可分配。相邻重复段点数变化不能单凭此数据归因为机械或采集问题。电流迟滞、框架倾斜、光斑、局部遮挡、运动异常及分行相位均可能造成错位/条纹。图中右侧和底部亮区可包含扫出胶带后的透光区域，不能自动视为错误像素。

因此结果是**保留原始数据的估计重构**，不是绝对位置标定。可以在副本中将 `phase_offset_mm` 改为正/负半个像素，比较配准敏感性；它按时间向后/向前移动窗口，反向行的空间偏移方向相反。不要为了匹配照片逐行人工拉直轮廓。只有加入运动日志/实际位置数据后，才能进一步区分这些来源。

## 复现与文件

在项目根目录安装 `reconstruction/requirements.txt` 中依赖后运行：

```text
python experiments/2026-09-28/rebuild.py
```

会重新生成五组窗口及结果，运行前保留自己的修改副本。只重做某组且保持窗口不变时，用通用 `reconstruction/reconstruct.py run --config <该组config.json> --overwrite`。

每组 `raw/current.xls` 为原始字节；`config.json` 为参数和锚点；`results/reconstruction.npz`为全量数值及映射；两个CSV分别给出像素→点和点→像素，`row=-1`表示未用于成像。时间戳不存在，所以不伪造I–t横轴。共享现场照片集中在 `setup/`，文件名与原始名称的对应见 `sources.json`。

## 运动参数反馈

用户报告已尝试最快10 mm/s、最慢10 μm/s，没有保留位移/时间测量记录；不能称为最高/最低平稳速度的定量测定。当前1 mm导程、整数RPM命令下，10 μm/s请求舍入为1 RPM，名义线速度16.667 μm/s；10 mm/s请求对应600 RPM。实际速度仍需测量。

最小有效位移未测得，肉眼无法分辨不是“没动”的证据。0.3125 μm是当前200整步×16细分、1 mm导程下单脉冲名义位移，不是实测精度。三个测试副本共享驱动核心，正式工程通过不同配置选择测试；01/02/03安全检查工程本来就共用检查过程，正式04才执行各自测试。

本版已增加 [独立X/Y速度](../../docs/hardware/independent-axis-speeds.md)。旧数据使用旧共享速度配置，不会因软件更新重新解释为低速Y测量。单向每行仍回程并换Y；双向25行末端X在远端，50/100行末端X在起始侧，最后一次Y步进后到名义高度。
